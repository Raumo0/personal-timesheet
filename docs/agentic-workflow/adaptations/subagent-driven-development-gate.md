# `subagent-driven-development` Adaptation

The approved local adaptation executes decimal task IDs from an approved
OpenSpec `tasks.md`. Discovery and plan changes return to the current
`$openspec-*` skills; no separate plan is created.

Each task uses the registered implementer profile, deterministic validation,
and an independent reviewer profile. The controller stops at declared Human
Gates and before controlled completion. Commit authority is never implied.

Focused coverage lives in
`tests/test_subagent_driven_development_adaptation.py`.
