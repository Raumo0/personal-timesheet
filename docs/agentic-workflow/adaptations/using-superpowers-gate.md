# `using-superpowers` Adaptation

The approved local adaptation keeps this skill as the mandatory skill router.
In repositories governed by OpenSpec it routes discovery, proposal creation,
artifact updates, and execution through `$openspec-explore`,
`$openspec-propose`, `$openspec-update-change`, and `$openspec-apply-change`.

`brainstorming` and `writing-plans` may remain installed, but they must not
create a parallel discovery or planning authority while OpenSpec owns the
work. Declared Human Gates remain mandatory.

Focused coverage lives in `tests/test_using_superpowers_adaptation.py`.
